# ENTREW V1 design decisions

These decisions resolve only the bounded questions in the supplied handoff. They preserve the backendless, one-contract, public GitHub evidence scope.

1. **Evidence trust.** A verified GitHub repository and commit identity are mandatory. Fetch only GitHub API endpoints built from a sanitized `owner/repo`, a 40-hex commit SHA, and explicit relative evidence paths. A response that proves a wrong repository, wrong commit, wrong marker, or missing marker at an already verified commit is a deterministic `NOT_ESTABLISHED` provenance failure. Transport errors, rate limits, untrusted redirects, malformed responses, invalid source encoding, and oversized content remain `INCONCLUSIVE` unless another reliable negative criterion independently establishes `NOT_ESTABLISHED`. Raw-host retrieval is disabled because it cannot independently bind bytes to the exact repository and commit. The API 404 for the marker is considered conclusive only after repository and commit identity have been verified.
2. **Marker.** `.entrew/claim.json` binds the canonical program ID, applicant wallet, normalized repository, and a random nonce. The evaluated full SHA is bound by the independently fetched commit object and stored revision. Do not put the SHA in its own committed marker. Marker presence does not establish human identity, authorship, or legal ownership.
3. **Deadline.** The contract compares its deterministic transaction timestamp against the immutable deadline on every write. A transaction whose execution timestamp is at or past the deadline is rejected, including one submitted earlier but finalized later. Browser time is advisory.
4. **Retries and revisions.** Retain the proposed cap of four distinct revision snapshots and two inconclusive rechecks per snapshot, each after a 10-minute cooldown. A conclusive snapshot cannot be reviewed again. Each quota is contract-enforced; protocol `UNDETERMINED` is not an app-level retry or result.
5. **Persistence bounds.** Persist bounded repository/SHA/path identities, the canonical submission digest, normalized evidence fingerprints, a compact provenance classification, the complete criterion vector, and bounded explanations. Do not persist full source files or claim markers on chain. Reject evidence that exceeds both per-file and total decoded-character caps; never silently truncate positive evidence.
6. **Signature provenance.** Signed Git commits are optional. This implementation will report exact revision binding separately and will not claim GitHub signature verification unless the selected runtime independently validates it.
7. **Public reads and pagination.** Use count plus hard-capped page reads (25 items); IDs remain append-only and page contents are read from a fixed offset. The browser retries if a concurrent append changes a count/page boundary. No unbounded list API.
8. **SDK and runtime compatibility.** Pin the requested CLI and `genlayer-js` versions, and isolate SDK calls behind a browser client module. Treat built-in SDK finality helpers as unverified until exercised against Studionet 61999; only a finalized successful transaction plus finalized contract readback can confirm an action. If the pinned runtime cannot independently retrieve and evaluate evidence inside both leader and validator execution, stop release rather than replacing GenLayer with a centralized decision service.
9. **Hosting.** Use a static App Router export and query IDs for record pages. Hosting rewrites may serve `index.html` for deep links but do not add product logic. If the selected host's static deep links are not verified, release documentation must say so.
10. **Product identity.** Keep the ENTREW name and Evidence Atlas visual system from the handoff. No trademark/domain clearance is implied.

## Release implications

These decisions do not claim implementation, performance, semantic accuracy, deployment, or browser verification. The 24,000-character source ceiling and network request limits must still be validated against the actual 0.39.1 GenVM. A limitation in GitHub's public API or GenLayer's nondeterministic network boundary must fail closed and be recorded, not moved into a secret backend.
